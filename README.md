# Pravasa AI — Karnataka Tourism Intelligence Frontend

Official frontend web application for **Pravasa AI**, providing verified travel intelligence across all 31 districts of Karnataka.

## ✨ Features

- **Multilingual Support**: Real-time Kannada (`ಕನ್ನಡ`) and English UI toggle.
- **Interactive Karnataka Tourism Map**: Built with Leaflet, custom markers, district filtering, and real-time navigation.
- **AI Travel Companion**: Floating AI assistant powered by Gemini for verified travel advice, temple timings, routes, and emergency info.
- **Verified Itinerary Builder**: Multi-day trip planner with budget estimation, vehicle modes, and route guidance.
- **Official Travel Advisories**: Live banner notifications for road clearances, weather warnings, and forest permits.
- **Safety & SOS 112**: Emergency assistance hub with direct helpline dials and police reporting.
- **Budget Calculator & Crowd Predictor**: Real-time crowd index and budget allocation tools.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The frontend will run at `http://localhost:5173`.

### Build for Production

```bash
npm run build
```

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **Maps**: Leaflet & React-Leaflet
- **Charts**: Recharts
- **Icons**: Lucide React
